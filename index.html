One-time setup needed

This app saves to Supabase and signs in with Google. Until it's connected, sign-in is disabled:

  1. Create a free project at supabase.com
  2. Run the SQL from README.md
  3. Turn on the Google provider under Authentication → Providers
  4. Paste your project URL + key into js/config.js

Full step-by-step walkthrough: README.md
